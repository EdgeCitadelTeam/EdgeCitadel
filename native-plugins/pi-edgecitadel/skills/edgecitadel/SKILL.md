# EdgeCitadel

Use the `edgecitadel_*` extension tools. Diagnose connectivity before retrying,
preserve task IDs, and query status for correlation. Inbox visibility is not
acceptance: request user approval when appropriate, then record `accepted`,
`running`, and one terminal state. This Agent is unavailable after Pi exits.
Include the completed output or structured failure in the terminal update.
