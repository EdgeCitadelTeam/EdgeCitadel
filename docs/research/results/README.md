# Research Benchmark Results

JSON files in this directory are generated by `scripts/research/run_agent_benchmark.py`.
They are research artifacts and can be regenerated from a running local stack.

Native baseline command:

```bash
PYTHONPATH=. \
python3 scripts/research/run_agent_benchmark.py \
  --workloads native --trials 30 --api-base http://localhost/api --nats-url nats://127.0.0.1:4222
```

Add `--render-md` to write a compact Markdown summary next to each JSON file.
