## Implemented behavior

See [package API and operation guide](../../agent-packages/jev/README.md).
JEV provides `jev.run` and `jev.resume` through the existing command endpoint,
serial one-step or execution/review workflows, request deduplication, stable child
IDs, explicit recovery and bounded waits. Agentd owns task/result authority.
Managed Agents can read the roster for capability/presence filtering; dispatch
still enforces the package grant. Caller-reserved IDs in trace dispatch preserve
atomic permission, child-task and trace persistence.

The dashboard retains structured JEV progress, shows the actual executor, links
child tasks and supports Continue. A live HTTP-browser test exposed unavailable
`crypto.randomUUID()` on `http://jim-eq`; request IDs now use cryptographically
random `getRandomValues()` bytes with UUIDv4 version/variant bits. This path is
covered by a test where randomUUID is unavailable.
